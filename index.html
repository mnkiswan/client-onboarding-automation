02 — STEP BY STEP

What each step does

01
Zoho Forms

Intake form is submitted

A client fills in one standard form. Every new client arrives in the same shape, so nothing has to be chased by email.

02
Zoho CRM

Create the account in CRM

Creates the company account record. The rest of the flow hangs off this record.

03
Zoho CRM

Create or update the contact

Creates the person, or updates them if they already exist, so repeat clients don't get duplicates.

04
Zoho CRM

Create the deal

Opens a deal so the sales pipeline shows the new client from the first minute.

05
Zoho Writer

Merge and email the welcome document

Fills a Writer template with the client's details and emails it. Every client gets the same professional pack.

06
Zoho Projects

Create the task list in Projects

Creates the delivery task list for this client.

07
Decision

Route by client segment

Enterprise, Group or Default. Each segment gets its own set of onboarding tasks, so enterprise work isn't handled like a small account.

08
Zoho Projects

Create the segment's tasks and subtasks

The right task plan is created for the segment, with subtasks, and assigned for kickoff.

03 — THE PROBLEM

Onboarding meant re-typing the same client three times

Intake came in by email and phone, in different formats. Someone then re-typed it into the CRM, wrote a welcome document from scratch, and built the kickoff tasks by hand. Every new client repeated the same three hours of admin.

04 — THE BUSINESS IMPACT

Why this workflow is worth building

1 form

One intake

Every client is captured once, in the same structure. Nothing is re-typed.

Same day

Delivery starts faster

The Projects task plan exists as soon as the form is submitted, not after someone finds time for it.

Zero

Forgotten steps

Account, contact, deal, document and tasks are created in one run, in order, every time.

Visible

Failures are caught

The error branch sends an alert task when a CRM or Writer step fails, so a broken run shows up instead of disappearing.
